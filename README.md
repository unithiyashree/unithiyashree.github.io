# unithiyashree.github.io

Personal academic website for Nithiya Shree Uppara — PhD student in Psychology at Arizona State University.

## Pages

- **Home** (`index.html`) — Bio, education, interests, and professional experience
- **Publications** (`publications.html`) — Conference papers and posters
- **Research** (`research.html`) — Research experience across ASU, NYU, UC-Davis, and IIITH

## File Structure

```
unithiyashree.github.io/
├── index.html              # Home page
├── publications.html       # Publications page
├── research.html           # Research page
├── README.md
└── assets/
    ├── css/
    │   └── styles.css      # All styles (light/dark mode)
    ├── js/
    │   └── scripts.js      # Dark mode toggle, mobile nav, back-to-top
    ├── images/
    │   └── Nithiya.jpg     # Profile photo
    └── pdf/
        ├── Nithiya_Resume2026.pdf
        ├── ISIR-2017.pdf
        └── PETMEI-Paper.pdf
```

## Features

- Clean, minimal design inspired by Hugo Academic CV
- Light/dark mode toggle (persisted in localStorage)
- Responsive layout with mobile hamburger menu
- Inter font family via Google Fonts
- Font Awesome icons for social links and UI elements
- Back-to-top button
